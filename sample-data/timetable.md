# Timetable data — Class 1 to Class 5 (section A), session 2026-27

There is **no CSV import for the timetable** — you enter it in **Timetable → Class timetable**
(pick the class + section, then choose Subject + Teacher for each Day × Period cell).
Import **Subjects** and **Teachers** first, then fill these grids.

## Bell schedule (Timetable → Schedule / config)
- **7 periods** a day, **working days Mon–Sat**.
- **Mon–Fri:** Period 1–7.
- **Saturday:** only Period 1–5 are used (leave P6, P7 empty).
